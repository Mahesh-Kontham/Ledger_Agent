# LedgerTruth: Your money, verified.

AI receipt-to-ledger bookkeeper with three role-based experiences (Individual, Business, Admin).

## Run (Windows PowerShell)
```powershell
cd D:\LEDGER_Agent\ledgertruth
pip install -r requirements.txt
copy .env.example .env               # then set GEMINI_API_KEY and the 3 DEMO_*_PW passwords
python scripts\make_samples.py       # sample receipts + bank CSV
python scripts\seed_users.py         # demo accounts (also runs automatically on first start)
python -m streamlit run app.py
python -m pytest -q                  # 50 tests, no API key needed
```

Demo logins: `user@demo` (Individual), `business@demo` (Business), `admin@demo` (Admin). Passwords are the values in `.env`.

## Known limitations (PRD §17)
- The fraud score comes from a mock unless `FRAUD_MCP_URL` is set.
- FX rates come from a fixed sample table.
- The bank feed is a CSV upload.
- "Probable card fee" is a heuristic, so the UI asks you to confirm it.

See `DECISIONS.md` and PRD Section 18.
